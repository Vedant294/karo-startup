### Which AI Tool Did You Use?

### Why did you design the page the way you did?
I approached the design using a **"Vivid Pastel Glassmorphism"** aesthetic. The goal was to strike the perfect balance between a highly professional, investor-grade platform and an energetic, welcoming environment for founders from Tier-2 and Tier-3 cities.

*   **Color & Gradient:** The bright, animated, cotton-candy gradient background grabs attention and feels distinctly modern, breaking away from boring, traditional corporate white layouts without being overly dark or aggressive.
*   **Glassmorphism Cards:** The use of white translucent 'glass' cards (`backdrop-blur`) ensures that the text (deep blue/slate) is perfectly readable and accessible, while allowing the vibrant background to shine through seamlessly. 
*   **Structured Hierarchy:** I rigorously followed the assignment parameters layout. Clean iconography and perfectly compartmentalized sections (like the 4-step process and the dedicated 'About KaroStartup' section) immediately establish trust and authority without overwhelming the user, ensuring the site is fully mobile-responsive and feels like a real, scalable product.

## 🛠️ Tech Stack & Local Setup

This project was built using **React** and **Vite** with **Tailwind CSS**.

To run this project locally on your machine:

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run the Development Server:**
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.
